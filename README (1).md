# EDA and Visualization in Fashion Trends

Week 3 task: Junior Data Science Analyst Internship.

Exploratory data analysis of fashion categories (Athleisure, Sustainable Wear, Streetwear, Ethnic Wear, Formal Wear, Y2K Revival): data cleaning, summary statistics, correlation, outlier detection (IQR) and six visualizations.

## Files
- `fashion_eda.py` : full pipeline (dataset generation, cleaning, statistics, charts)
- `fashion_illustrative_raw.csv` / `fashion_illustrative_clean.csv` : raw and cleaned data
- `Week3_EDA_Fashion_Trends_Report.docx` : full report

## Note
The dataset is illustrative (simulated with the structure of public fashion datasets). To use real data, replace the CSV with a Kaggle or Google Trends export that has the same columns.

## Run
```
pip install pandas numpy matplotlib
python fashion_eda.py
```
